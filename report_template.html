The objective of this Industry Practice Project is to engineer a production-ready Vehicle Rental Management System (VRMS). The system streamlines vehicle reservations, provides transparent multi-tiered pricing, automates legal contract generation, and equips fleet administrators with real-time telematics, maintenance auditing, and revenue analytics.

1.2 System Modules

Customer Fleet & Booking Engine: Multi-parametric vehicle search (branch, dates, category, fuel type), interactive specs modals, automated date-difference duration calculation, add-ons (CDW, GPS, Child Seat), promo discounts (COLLEGE20), and instant printable voucher generation.

Digital Contracts & Inspections: Cryptographic digital signature hashes for rental agreements, pre-rental and post-rental vehicle inspection audits (odometer, fuel %, exterior/interior condition) for damage deposit settlement.

2. Relational Database Design & ER Model

Visual Entity-Relationship Diagram (ERD) and 3NF Normalization Justification

2.1 3NF Normalization Justification

The relational database design strictly enforces the Third Normal Form (3NF) to eliminate insertion, deletion, and update anomalies while maximizing query throughput and data integrity:

  • First Normal Form (1NF): All attributes contain atomic values. Multi-valued features are decoupled into vehicle_features.
  • Second Normal Form (2NF): Every non-key attribute is fully functionally dependent on the complete primary key.
  • Third Normal Form (3NF): All transitive dependencies are eliminated. Pricing classifications reside exclusively in vehicle_categories.

4. SQL DDL Implementation Scripts

ANSI SQL Table Definitions, Constraints, and Business Intelligence Views

-- 1. VEHICLES TABLE (Hardware Fleet Inventory)
CREATE TABLE vehicles (
    vehicle_id INTEGER PRIMARY KEY,
    category_id INTEGER NOT NULL,
    current_branch_id INTEGER NOT NULL,
    vin VARCHAR(17) NOT NULL UNIQUE,
    license_plate VARCHAR(20) NOT NULL UNIQUE,
    make VARCHAR(50) NOT NULL,
    model VARCHAR(50) NOT NULL,
    manufacture_year INTEGER NOT NULL CHECK (manufacture_year >= 2018),
    color VARCHAR(30) NOT NULL,
    odometer_km INTEGER NOT NULL DEFAULT 0,
    fuel_type VARCHAR(25) NOT NULL CHECK (fuel_type IN ('Petrol', 'Diesel', 'Electric', 'Hybrid')),
    transmission VARCHAR(20) NOT NULL CHECK (transmission IN ('Automatic', 'Manual')),
    seating_capacity INTEGER NOT NULL CHECK (seating_capacity >= 2),
    daily_rate DECIMAL(10, 2) NOT NULL CHECK (daily_rate > 0),
    status VARCHAR(25) DEFAULT 'AVAILABLE' CHECK (status IN ('AVAILABLE', 'RENTED', 'MAINTENANCE')),
    image_url VARCHAR(500),
    FOREIGN KEY (category_id) REFERENCES vehicle_categories(category_id) ON DELETE RESTRICT,
    FOREIGN KEY (current_branch_id) REFERENCES branches(branch_id) ON DELETE RESTRICT
);

-- 2. BOOKINGS TABLE (Central Fact Entity)
CREATE TABLE bookings (
    booking_id INTEGER PRIMARY KEY,
    booking_reference VARCHAR(30) NOT NULL UNIQUE,
    customer_id INTEGER NOT NULL,
    vehicle_id INTEGER NOT NULL,
    pickup_branch_id INTEGER NOT NULL,
    return_branch_id INTEGER NOT NULL,
    pickup_datetime TIMESTAMP NOT NULL,
    return_datetime TIMESTAMP NOT NULL,
    rental_duration_days INTEGER NOT NULL CHECK (rental_duration_days >= 1),
    daily_rate_applied DECIMAL(10, 2) NOT NULL,
    subtotal_amount DECIMAL(10, 2) NOT NULL,
    addon_amount DECIMAL(10, 2) DEFAULT 0.00,
    tax_amount DECIMAL(10, 2) NOT NULL,
    deposit_amount DECIMAL(10, 2) NOT NULL DEFAULT 200.00,
    total_amount DECIMAL(10, 2) NOT NULL,
    booking_status VARCHAR(25) DEFAULT 'CONFIRMED' CHECK (booking_status IN ('CONFIRMED', 'ACTIVE', 'COMPLETED')),
    FOREIGN KEY (customer_id) REFERENCES customer_profiles(customer_id) ON DELETE RESTRICT,
    FOREIGN KEY (vehicle_id) REFERENCES vehicles(vehicle_id) ON DELETE RESTRICT,
    FOREIGN KEY (pickup_branch_id) REFERENCES branches(branch_id) ON DELETE RESTRICT,
    FOREIGN KEY (return_branch_id) REFERENCES branches(branch_id) ON DELETE RESTRICT
);

-- 3. REPORTING VIEW: Active Rentals with Driver & Vehicle Details
CREATE VIEW v_active_rentals AS
SELECT 
    b.booking_reference,
    u.full_name AS customer_name,
    cp.driver_license_number,
    v.make || ' ' || v.model AS vehicle_model,
    v.license_plate,
    b.pickup_datetime,
    b.return_datetime,
    pb.branch_name AS pickup_location,
    b.total_amount
FROM bookings b
JOIN customer_profiles cp ON b.customer_id = cp.customer_id
JOIN users u ON cp.user_id = u.user_id
JOIN vehicles v ON b.vehicle_id = v.vehicle_id
JOIN branches pb ON b.pickup_branch_id = pb.branch_id
WHERE b.booking_status = 'ACTIVE';
